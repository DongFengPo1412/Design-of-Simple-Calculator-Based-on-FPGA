# 基于 FPGA & Verilog 的简易计算器设计项目 (Design of Simple Calculator Based on FPGA)

这是一个基于 **FPGA (Xilinx Artix-7)** 和 **Verilog HDL** 开发的简易计算器系列工程集合。本项目记录了在数字逻辑设计课程设计中，从最初的高级浮点数计算器构想，到串行移位驱动优化，再到最终实现的全过程。

仓库内包含了三个具有不同设计重点和技术特性的独立 Vivado 工程，分别展示了硬件设计的核心技能。

---

## 📂 仓库项目结构 (Repository Structure)

本项目共分为以下三个子目录，各自对应独立的 Vivado 物理工程：

### 1. 浮点运算计算器 (IEEE-754 标准版)
* **目录路径**：`float_calculator_ieee754/`
* **工程名称**：`cacu`
* **核心特性**：
  * 基于 **IEEE-754 单精度浮点数标准**（1位符号位、8位指数位、23位尾数位）设计。
  * 包含了独立的浮点运算单元模块 `ALU_float`，支持单精度浮点数的加法、减法、乘法，并处理了对阶、尾数求和与结果规格化等复杂状态。
  * 包含 `float_to_ieee754` 模块，用于将输入的实数（整数与小数部分）编码为 32-bit 标准 IEEE-754 格式。
  * 包含了按键输入解析和浮点数译码动态扫描数码管显示驱动。
* **开发状态**：核心算法和子模块已编写完毕，但顶层接线模块仍在调试阶段。适合作为进一步学习和改进 FPGA 浮点计算设计的起点。

### 2. 蜂鸣器整数计算器 (趣味按键奏乐版)
* **目录路径**：`integer_calculator_buzzer/`
* **工程名称**：`project_3`
* **核心特性**：
  * 实现完整的两位数整数四则运算（`+`、`-`、`*`、`/`），支持小数部分（非整除除法显示 2 位小数）和负数负号显示。
  * 拥有完善的矩阵键盘状态机扫描及消抖模块。
  * **增设蜂鸣器按键音/奏乐模块**：将矩阵键盘的每一个按键映射到特定的音符频率。当在键盘上输入数字或进行计算时，开发板上的蜂鸣器会播放对应音高的按键音，极具交互趣味性。
* **开发状态**：完全开发并经过硬件测试成功，可直接生成 Bitstream 下发运行。

### 3. 移位寄存器整数计算器 (74HC595 串口数显版)
* **目录路径**：`integer_calculator_74hc595/`
* **工程名称**：`calculator`
* **核心特性**：
  * 使用 **74HC595 移位寄存器芯片串行驱动 8 位七段数码管**。
  * 将原本并口直驱需要的 14 根 FPGA IO 引脚（6位位选 + 8位段选）缩减到**仅需 3 根控制引脚**（串行数据线 `ds`、移位时钟 `sclk`、锁存时钟 `rclk`），展现了出色的硬件引脚节省和串行通信控制时序能力。
  * 模块结构高度解耦分层，包含了独立的乘法器 `mult`、除法器 `div`、进制转换模块 `hex2bcd` 以及 5 状态核心控制状态机。
* **开发状态**：完全开发完毕并测试成功，是展示 FPGA 硬件驱动和精密时序控制能力的最佳作品。

## 🛠️ 开发环境与目标硬件 (Environment & Hardware)

* **开发软件**：Xilinx Vivado (推荐使用 2018.3 及以上版本)
* **硬件平台**：基于 **Xilinx Artix-7** 芯片的 FPGA 开发板（引脚约束基于依元素 **EGO1** 开发板进行分配）
* **语言规范**：Verilog-2001 标准

## 🚀 快速上手 (Quick Start)

每个工程目录下都已完成了“Git 瘦身”，移除了庞大的编译缓存（如 `.runs`、`.cache` 等文件夹），仅保留了核心源码。你可以通过以下步骤打开工程：

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/DongFengPo1412/Design-of-Simple-Calculator-Based-on-FPGA.git
   ```
2. 打开 **Xilinx Vivado** 软件。
3. 点击 **Open Project**，浏览并选中你想查看的子工程目录下的 `.xpr` 工程引导文件：
   * 浮点版：`float_calculator_ieee754/cacu.xpr`
   * 蜂鸣器整数版：`integer_calculator_buzzer/project_3.xpr`
   * 移位寄存器版：`integer_calculator_74hc595/calculator.xpr`
4. 打开后即可在 **Design Sources** 下直接查看完整的 Verilog 层次结构并进行仿真、综合或烧录。
