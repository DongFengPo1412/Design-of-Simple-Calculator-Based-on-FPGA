## 主版：入力と表示

[caculator.v](../integer_calculator_buzzer/project_3.srcs/sources_1/new/caculator.v) は `Caculator`、`cal`、`FreDiv`、`button`、`buzzermusic`、`Buzzercontrol` を定義します。`cal` のキー値0–9が数字、10–13が四則演算、14が等号、15がクリアです。入力は2桁で構成し、状態とキー保持判定で受理を決めます。同一数字の再入力には二つのスイッチも使います。

`a_reg`、`b_reg`、結果レジスタはそれぞれ21、7、21ビットです。負の差は絶対値とフラグで表し、完全な符号付き演算系ではありません。表示カウンタの0–5で6桁を選び、6・7は空きスロットです。公称1 kHz走査を各桁の1 kHz更新とみなせません。一部のクロック、走査カウンタ、ブザーレジスタには確定的な初期化・リセットがなく、シミュレーションで不定値が残る可能性があります。

連続演算の分岐はありますが、結果状態で別の演算子を選んでも `op` が更新されない経路があります。異なる演算を続ける場合の検証が必要で、一般的な数式入力の完成は確認できません。

## 分周・サンプリング・キー音

```math
f_{out}\approx\frac{f_{clk}}{2(\lfloor25000000/f_{req}\rfloor+1)}
```

```math
(b_2\land b_1\land b_0)\lor(\neg b_2\land b_1\land b_0)=b_1\land b_0
```

`FreDiv` は25,000,000を使用し、整数除算の商にカウンタが達すると出力を反転します。上式は入力クロックが既知の場合のコード上の計算です。50 MHz入力なら要求値1000/50に対して約1 kHz/50 Hzですが、実測値ではありません。走査クロックの両エッジと低速ボタンサンプリングにまたがる経路があり、同期とタイミング制約の十分性は未確認です。

3レジスタのボタン式は上記の `b1 & b0` に簡約されます。「3回連続一致」や厳密な20 msの応答時間を意味しません。74HC595側の時間計測式状態機械とは別実装です。

`buzzermusic` はキーで固定カウントを選び、`Buzzercontrol` が矩形波を生成します。演算完了時に別の楽曲を再生する構成ではありません。音程は入力クロックとカウント端点に依存します。

<a id="arithmetic"></a>

## 演算と表示の制約

- 演算部の `result <= a / b` と `%` にゼロ除算ガードがありません。後段のエラー表示だけでは演算を防げません。
- 余り `res` は4ビットで、15を超える値が切り捨てられ、小数2桁も誤る可能性があります。任意の2桁除数での精度は保証できません。
- 演算幅と表示可能範囲は一致せず、完全なオーバーフロー処理もありません。小数表示の試行は浮動小数点演算ではありません。
- [multiplication.v](../integer_calculator_buzzer/project_3.srcs/sources_1/new/multiplication.v) は主工程の活動RTLに含まれません。変数依存の生成条件や `wire` への裸の代入に構文・構造上の問題があり、合成済み乗算器として扱いません。
- 両 `.xpr` の `sim_1` に独立テストファイルは登録されていません。別置きテストは `$display`/`$stop` を使い、結果アサーションがありません。`sim1.v` には未定義モジュール参照と不正な負数リテラルもあります。

<a id="experiments"></a>

## 二つの実験版の状態

| モジュール | コードで確認した内容 | 統合上の不足 |
| --- | --- | --- |
| 74HC595 `key_scan` / `operation_ctrl` | 2段同期、時間計測によるチャタリング除去、入力状態、加減算と乗算ハンドシェイク | トップに乗算器がなく、除算器も未接続 |
| `mult` / `div` | 独立したシフト加算乗算・シフト減算除算。除算器にはゼロ除算分岐 | その保護をブザー版の機能に含めない |
| `hex2bcd` | シフトと、5以上のBCD桁への3加算 | 既定の27ビット入力は9桁・36ビット出力。トップの受け側は32ビット、表示は6桁 |
| `seg_disp` / `hc595_drive` | 段デコードと16ビットのシフト・ラッチ断片 | 走査制御が欠落。段入力は6ビットのみ。トップの `ds/sclk/rclk` を駆動する実体がない |
| 浮動小数点 `Top` と変換 | 二つの入力解析、形式変換、表示の実験 | 暗黙のスカラネット、未駆動クロック・信号、二つの変換器が同じ第1入力に接続、桁選択未接続。活動XDCは空 |
| `ALU_float` | 8状態、指数合わせ、仮数加減乗算、一部の正規化・丸め | 除算に商演算がない。乗除の符号がXORではなくOR。ゼロ・非正規化数・NaN/Inf・丸めが不完全 |

入力解析は連結と切り捨てを使い、完全な十進浮動小数点変換ではありません。`float_to_ieee754` は整数値から同じ整数を引くため小数部がゼロとなり、一般の値を正しく変換できません。出力変換も未完成です。

74HC595の `src/transcript` は2024-01-23のModelSim記録で、現在の `top.v` にない乗除算器・シフトドライバの実体とビット幅警告を示します。`src/test.v` と `sim/test.v` も別のインターフェース・刺激で、後者は現在のトップにない表示ポートを使います。過去の「Errors: 0」は現行ソースの検証結果ではありません。

## 資料と版の対応

主RTLはローカル `Documents/Vivado/project_3` の同名ファイルとバイト単位で一致します。浮動小数点の `Top.v` はローカル `cacu (1)` と一致し、`cacu(2)` とは異なります。両者の機能を混在させていません。
